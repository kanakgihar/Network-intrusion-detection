# data/

Place the raw UNSW-NB15 CSV here (it is git-ignored because it is large):

- `UNSW_NB15_training-set.csv` or `UNSW_NB15_testing-set.csv`
  from https://www.kaggle.com/datasets/ucimachinelearning/unsw-nb15-dataset

`sample_traffic.csv` is a 300-row, label-free demo file (held-out flows) that you can upload in the app.
